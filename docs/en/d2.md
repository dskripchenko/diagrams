# D2

```d2
direction: right
users: Users { shape: person }
cloud: AWS {
  api: API
  db: Database { shape: cylinder }
  api -> db: SQL
}
users -> cloud.api: HTTPS
cloud.db.style.fill: "#fde68a"
```

D2 has no header, so it is recognised by its statements — key–value pairs
and edges — when a source starts with no other syntax's keyword; pass
`syntax: 'd2'` to be sure. It is drawn with the flowchart's layout.

| Syntax | |
|---|---|
| `x`, `x: Label` | a shape |
| `a: Title { … }` | a container: shapes inside it; a shape with children is drawn as a frame |
| `a.b.c` | a path: `b` in `a`, `c` in `b` — declared on the spot |
| `a -> b`, `a <- b`, `a <-> b`, `a -- b`, `a -> b -> c: label` | edges, in chains, with a label |
| `a -> b { style.stroke: red; target-arrowhead.shape: diamond }` | edge attributes |
| `x.shape: cylinder`, `x { shape: cylinder; style.fill: "#fde68a" }` | attributes as keys or in a block |
| `direction: right` (or `down`, `left`, `up`) | the layout direction, of the diagram or of a container |
| `a: \|md … \|` | a block string: its text is the label |
| `#`, `;`, quoted keys | comments, separators, names with spaces or dots |

**Shapes:** rectangle, square, page, parallelogram, document, cylinder,
queue, package, step, callout, stored_data, person, diamond, oval, circle,
hexagon, cloud, text (code, class, sql_table and image draw as rectangles).
**Styles:** `fill`, `stroke`, `font-color`, `stroke-dash`, `stroke-width`;
`opacity: 0` hides an edge. **Arrowheads:** triangle, arrow, diamond,
filled-diamond, circle, filled-circle, cf-one, cf-many, cross. Icons,
tooltips, links, `near`, width and height are accepted and not drawn.
Imports (`@file`), variables, classes, globs and edge references
(`(a -> b)[0]`) are an error.
