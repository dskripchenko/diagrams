# Карта Уордли

```wardley
title Чайная
anchor Бизнес [0.95, 0.63]
component Чашка чая [0.79, 0.61]
component Чай [0.63, 0.81]
component Чайник [0.43, 0.35] (inertia)
component Электричество [0.1, 0.7] (outsource)
evolve Чайник 0.62
Бизнес->Чашка чая
Чашка чая->Чай
Чашка чая->Чайник
Чайник->Электричество; ограничивает
note Стандарт электросети [0.30, 0.49]
```

Язык OnlineWardleyMaps. Исходник с `component` или `anchor` в координатах
(или начинающийся с `wardley`) — карта Уордли. Координаты —
`[видимость, эволюция]`: видимость от 0 (не видно, внизу) до 1 (видно,
вверху), эволюция от 0 (зарождение, слева) до 1 (товар, справа).

| Синтаксис | |
|---|---|
| `title …` | заголовок |
| `anchor Имя [v, e]` | пользователь или потребность: жирный текст |
| `component Имя [v, e]` | компонент; `label [dx, dy]` сдвигает подпись |
| `… (inertia)` | полоса: инерция, сопротивление изменениям |
| `… (build)`, `(buy)`, `(outsource)` | как получен: подсветка вокруг |
| `market Имя [v, e]`, `ecosystem Имя [v, e]` | рынок или экосистема |
| `A->B`, `A->B; подпись` | зависимость |
| `A+>B`, `A+<>B` | поток ценности: пунктир |
| `evolve Имя 0.62` | куда движется: красный «призрак» на новой эволюции |
| `pipeline Имя [начало, конец]` | конвейер вариантов под компонентом |
| `note текст [v, e]` | заметка |
| `annotation 1 [[v, e], …] текст`, `annotations [v, e]` | номерные отметки и их легенда |
| `evolution A->B->C->D` | названия четырёх стадий |
| `style …`, `size …` | принимаются |

Границы стадий — обычные: 0.174, 0.4 и 0.7.
