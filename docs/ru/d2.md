# D2

```d2
direction: right
users: Пользователи { shape: person }
cloud: AWS {
  api: API
  db: База данных { shape: cylinder }
  api -> db: SQL
}
users -> cloud.api: HTTPS
cloud.db.style.fill: "#fde68a"
```

У D2 нет заголовка, поэтому он распознаётся по инструкциям — парам
«ключ: значение» и рёбрам, — когда исходник не начинается с ключевого слова
другого синтаксиса; для надёжности передайте `syntax: 'd2'`. Рисуется
раскладкой блок-схемы.

| Синтаксис | |
|---|---|
| `x`, `x: Подпись` | фигура |
| `a: Заголовок { … }` | контейнер: фигуры внутри; фигура с потомками рисуется рамкой |
| `a.b.c` | путь: `b` в `a`, `c` в `b` — объявляются на месте |
| `a -> b`, `a <- b`, `a <-> b`, `a -- b`, `a -> b -> c: подпись` | рёбра, цепочками, с подписью |
| `a -> b { style.stroke: red; target-arrowhead.shape: diamond }` | атрибуты ребра |
| `x.shape: cylinder`, `x { shape: cylinder; style.fill: "#fde68a" }` | атрибуты ключами или в блоке |
| `direction: right` (или `down`, `left`, `up`) | направление раскладки — всей диаграммы или контейнера |
| `a: \|md … \|` | блочная строка: её текст — подпись |
| `#`, `;`, ключи в кавычках | комментарии, разделители, имена с пробелами или точками |

**Фигуры:** rectangle, square, page, parallelogram, document, cylinder,
queue, package, step, callout, stored_data, person, diamond, oval, circle,
hexagon, cloud, text (code, class, sql_table и image рисуются
прямоугольником). **Стили:** `fill`, `stroke`, `font-color`,
`stroke-dash`, `stroke-width`; `opacity: 0` скрывает ребро. **Наконечники:**
triangle, arrow, diamond, filled-diamond, circle, filled-circle, cf-one,
cf-many, cross. Иконки, подсказки, ссылки, `near`, ширина и высота
принимаются и не рисуются. Импорты (`@file`), переменные, классы, шаблоны
`*` и ссылки на рёбра (`(a -> b)[0]`) — ошибка.
