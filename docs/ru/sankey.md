# Диаграмма Санкей

```mermaid
sankey-beta
  Солнце,Сеть,40
  Ветер,Сеть,30
  Сеть,Дома,45
  Сеть,Промышленность,25
  Промышленность,"Экспорт, за рубеж",10
```

Потоки между узлами — ленты шириной в их значение. Один поток в строке:
источник, получатель, значение через запятую; имя с запятой берётся в
двойные кавычки, `""` — кавычка внутри.

Узлы стоят колонками: каждый на колонку правее самого дальнего узла,
который в него втекает, конечные — в последней колонке. Высота узла —
большее из того, что втекает, и того, что вытекает. Потоки не должны идти
по кругу — это ошибка. До 1 000 потоков.
