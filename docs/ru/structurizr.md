# Structurizr DSL

```structurizr
workspace {
  model {
    user = person "Покупатель"
    shop = softwareSystem "Магазин" {
      web = container "Сайт" "Витрина" "React"
      db = container "Заказы" "" "PostgreSQL" "Database"
    }
    psp = softwareSystem "Платежи" "" "External"
    user -> web "Пользуется" "HTTPS"
    web -> db "Читает и пишет"
    web -> psp "Списывает оплату"
  }
  views {
    container shop {
      include *
      autolayout lr
    }
  }
}
```

Исходник, который начинается с `workspace`, — это Structurizr DSL: одна
модель архитектуры и её представления (views). Рисуется первое
представление как [диаграмма C4](c4.md); без представлений — ландшафт
людей и программных систем.

| Синтаксис | |
|---|---|
| `id = person "Имя" "Описание" "Теги"` | человек (`id =` необязателен) |
| `id = softwareSystem "Имя" "Описание" "Теги" { … }` | программная система со своими контейнерами |
| `id = container "Имя" "Описание" "Технология" "Теги" { … }` | контейнер со своими компонентами |
| `id = component "Имя" "Описание" "Технология" "Теги"` | компонент |
| `tags "…"`, `description "…"`, `technology "…"` внутри элемента | дополнительные сведения |
| `a -> b "Описание" "Технология"`, `-> b` внутри элемента | связи |
| `group "Имя" { … }` | читается; его элементы относятся к охватывающей области |
| `systemLandscape`, `systemContext x`, `container x`, `component x` в `views` | рисуемое представление (первое); `autolayout lr` — слева направо |
| `element "Тег" { shape Cylinder }` в `styles` | форма для тега: `Cylinder`, `Pipe`, `Person` |

**Что показывает представление.** Контекст — людей и программные системы.
Контейнеры — контейнеры системы внутри её границы и людей и системы вокруг.
Компоненты — компоненты контейнера внутри его границы и контейнеры, людей и
системы вокруг. Связи между элементами, которых в представлении нет,
рисуются между их ближайшими видимыми родителями (вызов контейнером другой
системы становится связью системы), по одному разу.

**Теги.** `External` (или `location External`) — внешний элемент;
`Database` — цилиндр, `Queue` — труба. Представления развёртывания и
динамические, `!docs`, `!adrs`, `!include` и скрипты не читаются.
