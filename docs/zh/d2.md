# D2

```d2
direction: right
users: 用户 { shape: person }
cloud: AWS {
  api: API
  db: 数据库 { shape: cylinder }
  api -> db: SQL
}
users -> cloud.api: HTTPS
cloud.db.style.fill: "#fde68a"
```

D2 没有头部，因此当源码不以其他语法的关键字开头时，按其语句（键值对和边）识别；如需确保，请传入 `syntax: 'd2'`。使用流程图的布局绘制。

| 语法 | |
|---|---|
| `x`、`x: 标签` | 形状 |
| `a: 标题 { … }` | 容器：其中包含形状；有子项的形状绘制为框 |
| `a.b.c` | 路径：`a` 中的 `b`，`b` 中的 `c`——就地声明 |
| `a -> b`、`a <- b`、`a <-> b`、`a -- b`、`a -> b -> c: 标签` | 边，可成链，带标签 |
| `a -> b { style.stroke: red; target-arrowhead.shape: diamond }` | 边属性 |
| `x.shape: cylinder`、`x { shape: cylinder; style.fill: "#fde68a" }` | 以键或块的形式写属性 |
| `direction: right`（或 `down`、`left`、`up`） | 整张图或某个容器的布局方向 |
| `a: \|md … \|` | 块字符串：其文本即标签 |
| `#`、`;`、带引号的键 | 注释、分隔符、含空格或点的名称 |

**形状：** rectangle、square、page、parallelogram、document、cylinder、queue、package、step、callout、stored_data、person、diamond、oval、circle、hexagon、cloud、text（code、class、sql_table 和 image 绘制为矩形）。**样式：** `fill`、`stroke`、`font-color`、`stroke-dash`、`stroke-width`；`opacity: 0` 隐藏边。**箭头：** triangle、arrow、diamond、filled-diamond、circle、filled-circle、cf-one、cf-many、cross。图标、提示、链接、`near`、宽度和高度被接受但不绘制。导入（`@file`）、变量、类、通配符和边引用（`(a -> b)[0]`）会报错。
