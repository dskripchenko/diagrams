# D2

```d2
direction: right
users: Benutzer { shape: person }
cloud: AWS {
  api: API
  db: Datenbank { shape: cylinder }
  api -> db: SQL
}
users -> cloud.api: HTTPS
cloud.db.style.fill: "#fde68a"
```

D2 hat keinen Kopf und wird daher an seinen Anweisungen erkannt —
Schlüssel-Wert-Paaren und Kanten —, wenn eine Quelle mit keinem
Schlüsselwort einer anderen Syntax beginnt; sicherer ist `syntax: 'd2'`.
Gezeichnet wird mit dem Layout des Flussdiagramms.

| Syntax | |
|---|---|
| `x`, `x: Beschriftung` | eine Form |
| `a: Titel { … }` | ein Container: Formen darin; eine Form mit Kindern wird als Rahmen gezeichnet |
| `a.b.c` | ein Pfad: `b` in `a`, `c` in `b` — an Ort und Stelle deklariert |
| `a -> b`, `a <- b`, `a <-> b`, `a -- b`, `a -> b -> c: Beschriftung` | Kanten, in Ketten, mit Beschriftung |
| `a -> b { style.stroke: red; target-arrowhead.shape: diamond }` | Kantenattribute |
| `x.shape: cylinder`, `x { shape: cylinder; style.fill: "#fde68a" }` | Attribute als Schlüssel oder in einem Block |
| `direction: right` (oder `down`, `left`, `up`) | die Layoutrichtung, des Diagramms oder eines Containers |
| `a: \|md … \|` | ein Blockstring: sein Text ist die Beschriftung |
| `#`, `;`, Schlüssel in Anführungszeichen | Kommentare, Trenner, Namen mit Leerzeichen oder Punkten |

**Formen:** rectangle, square, page, parallelogram, document, cylinder,
queue, package, step, callout, stored_data, person, diamond, oval, circle,
hexagon, cloud, text (code, class, sql_table und image als Rechteck).
**Stile:** `fill`, `stroke`, `font-color`, `stroke-dash`, `stroke-width`;
`opacity: 0` verbirgt eine Kante. **Pfeilspitzen:** triangle, arrow,
diamond, filled-diamond, circle, filled-circle, cf-one, cf-many, cross.
Icons, Tooltips, Links, `near`, Breite und Höhe werden akzeptiert und nicht
gezeichnet. Importe (`@file`), Variablen, Klassen, Globs und
Kantenreferenzen (`(a -> b)[0]`) sind ein Fehler.
